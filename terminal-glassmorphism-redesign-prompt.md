- Next.js 16 (App Router)

# Your Goal

Transform the current interface into a premium developer-focused SaaS experience by combining two aesthetics:

- Modern Terminal Interface
- Glassmorphism

---

# Design Philosophy

The design should emphasize:

- Minimalism
- Simplicity
- Excellent readability
- Clear hierarchy
- Spacious layouts
- Professional appearance
- High usability
- Consistency

Avoid unnecessary decoration.

Avoid visual noise.

Every UI element should have a purpose.

# Terminal Style

Use terminal inspiration subtly.

Examples include:

- Developer-oriented appearance
- Monospace typography for code-like areas
- Command-inspired buttons
- Terminal prompts
- Console-style panels
- Code snippets
- Developer dashboard feeling

Avoid:

- Hacker movie aesthetics
- Matrix effects
- ASCII decorations
- Neon overload
- Retro interfaces

The terminal style should be elegant and understated.

---

# Glassmorphism

Include:

- Frosted glass cards
- Background blur
- Semi-transparent surfaces
- Soft borders
- Layered depth
- Soft shadows

Never sacrifice readability.

## Color System

The application should **NOT** use the typical AI product color palette.

Avoid:

- Purple gradients
- Neon blue
- Bright cyan
- Futuristic AI aesthetics
- Rainbow gradients
- Excessive glowing effects

Instead, build the visual identity around a **professional green color system**.

### Primary Color

Use a modern emerald green as the primary brand color.

Suggested primary:

**#16A34A**

Use lighter and darker shades consistently throughout the interface.

Example palette:

- Green 50 → #F0FDF4
- Green 100 → #DCFCE7
- Green 200 → #BBF7D0
- Green 300 → #86EFAC
- Green 400 → #4ADE80
- Green 500 → #22C55E
- Green 600 → #16A34A (Primary)
- Green 700 → #15803D
- Green 800 → #166534
- Green 900 → #14532D

### Neutral Colors

Build the rest of the interface using neutral dark tones.

Suggested palette:

- Background: #0B0F0C
- Secondary Background: #121815
- Surface: #1A211D
- Glass Surface: rgba(26, 33, 29, 0.65)
- Border: rgba(255,255,255,0.08)

Typography:

- Primary Text: #F8FAFC
- Secondary Text: #CBD5E1
- Muted Text: #94A3B8

### Accent Usage

Green should be used intentionally for:

- Primary buttons
- Active navigation items
- Focus states
- Links
- Selected elements
- Success states
- Progress indicators

Avoid using green excessively across the entire interface.

Most of the UI should rely on neutral colors, allowing the green accent to naturally guide the user's attention.

### Overall Mood

The interface should feel:

- Calm
- Professional
- Premium
- Modern
- Minimal
- Elegant

It should inspire trust rather than trying to look futuristic or "AI-powered."
